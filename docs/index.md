# Entity Manager

An entity manager for LLMs.

## Overview

Entity Manager is a tool designed to help manage and track entities across your codebase. It provides a clean interface for working with entities in the context of Large Language Model applications.

## Features

- Entity management and tracking
- GitHub integration
- Notion integration
- CLI interface with multiple commands

## Quick Start

```bash
# Install the package
uv pip install entity-manager

# Run the CLI
entity-manager --help
```

For more detailed installation and usage instructions, see the [Getting Started](getting-started.md) guide.
